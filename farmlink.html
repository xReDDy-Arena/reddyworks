PROIECTUL

Ce este FarmLink?

FarmLink este un telefon virtual creat pentru Farming Simulator 25.

Scopul proiectului este să ofere jucătorului o interfață modernă prin care să poată accesa rapid diferite informații și funcții ale fermei fără să părăsească experiența de joc.

Telefonul este conceput pentru a putea fi folosit atât atunci când jucătorul este pe jos, cât și atunci când se află într-un vehicul.

Proiectul este încă în dezvoltare, iar funcțiile pot fi modificate sau îmbunătățite până la lansarea versiunii publice.
